[02] Gate codes, safely

It can't leak a gate code
it never sees.

A phone agent that can reset gate codes is only as safe as what it knows. Prompt rules alone were not enough in our testing, so the fix is architectural: the agent is only ever handed the caller's own record.

  1. One record per call, at most. The agent gets the caller's own record, matched by the number that is calling, or by details the caller has given where every field must match exactly. Never other tenants' records.
  2. No match, no record. If two accounts share a phone number, or the details don't line up, the agent gets neither and treats the caller as unverified.
  3. Only the fields it needs. For the storage agent that is name, unit, size and balance. Free-text notes are never passed, and any value that reads like an instruction to the AI is dropped.
  4. Verify, then reset. Before it touches a gate code it confirms the caller's name and unit number. Callers claiming to be the owner or staff get no special treatment: the claim changes no rule.

[07] Straight answers

What storage operators
ask us first.

Could someone talk it into giving out another tenant's gate code?

It verifies the caller's name and unit number before it resets anything, and it is never handed other tenants' records in the first place: each call gets at most the caller's own record, matched by caller ID or by details that all match exactly. We test this with a simulated caller who asks for his sister's unit and gate code. In our security runs, cross-customer leaks went from 14 calls to 0 once the agent stopped seeing other people's data.

How does it take payments without reading card numbers out loud?

The tenant enters the card on the phone keypad, and the agent confirms the amount. It is told never to read a card number back, and one of our test callers reads the full card number out loud on purpose to check that it doesn't repeat it. It can also enrol the tenant in autopay.

Will it quote a unit size or price we don't offer?

No. It quotes only the sizes and monthly prices in its inventory and is not allowed to invent one or agree to a discount. Every test run checks each price the agent says against the real price list in code, not by ear.

Does it connect to our management software?

The demo writes every call to its own operator dashboard through a webhook. For your facility we connect it to your management software through that software's API or a webhook, and confirm on the fit call exactly which records it can read and write before we build.

What does it do with a call it shouldn't handle?

Anything it doesn't know, like insurance terms or corporate policy, gets a manager callback with the number taken. If a caller reports smoke, fire, flooding or a break-in, it tells them to get to safety and call 911 first. Both paths are in the test suite.

Does it use our existing number, and how long until it's live?

It sits on the number you already have, through LC Phone or your own Twilio account, so tenants see no change. It's live five to seven days after the call where you give us your unit sizes, prices, gate and payment rules, and the calls you miss most.
